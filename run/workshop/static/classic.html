01 / THE SYSTEM

From observation to accountable action.

Follow a video observation through perception, specialist analysis, agent decisions and human review—then use the execution evidence to improve the agent.

NVIDIA AGENT TOOLKIT / THE OVERALL STACK

Models provide intelligence. Tools and skills give the agent capabilities. The harness coordinates the work, and OpenShell provides the runtime controls. Relay, Gym and RL help us observe, evaluate and improve behavior.

01 / PERCEPTION

NVIDIA VSS

The Video Search and Summarization blueprint turns video into a scene description that the agent can use as evidence.

Video → observation
02 / REASONING + SPECIALIZATION

Lightning + the LoRA adapter

The base model chooses actions and drafts text. Your trained adapter supplies the organization’s activity categories, confidence grades and destinations.

Observation → structured triage
03 / EXECUTION + ACCESS

Agent harness + OpenShell

The harness manages prompts, state and tool calls. In the target deployment, OpenShell surrounds it and enforces access to models, tools and mounted data.

Task → policy-controlled actions
04 / MODEL ROUTING

NeMo Switchyard

Directs model requests to the right capability. This workshop uses explicit routes: base model for reasoning and drafting; adapter for specialist triage.

Model request → base or specialist
05 / OBSERVABILITY

NeMo Relay

Records model and tool events so we can inspect choices, timings and failures. Those traces help identify behaviors that need better tests or training.

Execution → inspectable evidence
06 / EVALUATION + LEARNING

NeMo Gym + NeMo RL

Gym verifies behavior in repeatable tasks and returns rewards. RL uses those rewards to train a candidate policy, which must be evaluated and approved before deployment.

Verified rewards → candidate policy

The walkthrough combines live agent tools, recorded traces and a real CPU teaching experiment. OpenShell deployment and agent-invoked learning skills are shown as the target architecture.
