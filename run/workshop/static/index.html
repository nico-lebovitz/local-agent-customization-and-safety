What supports VSS behind the scenes?

VST manages video access: clips, snapshots, and the video list. The local deployment also includes stream and sensor services, Redis and PostgreSQL, and Phoenix for VSS tracing. NVIDIA NIM services serve the Nano and Cosmos models.

This walkthrough covers the installed base profile. Search and alerts are separate profiles. The workshop agent uses NeMo Relay for its own traces, shown in the next section.
